📘 參、鏈路預算系統參數調校與控制策略指引 (Thesis Tuning Strategy)

一、 大氣/降雨線性衰減率 ($\alpha_{\text{atm}}$) 調整策略 (ITU-R P.838 / P.676)

用於模擬惡劣天候對微波信號的吸收與散射。在撰寫論文時，可設計以下對照情境（以 $0.1\text{ dB/km}$ 為調校單位步進）：

  • 情境 A (常規晴朗天氣): 晴空萬里的大氣吸收極低，請設為 **$0.0\text{ dB/km}$**，以確立基準 (Baseline) 效能。
  • 情境 B (中度降雨 / 海霧干擾): 模擬海上發生梅雨或中等降雨，建議調整為 **$0.1 \sim 0.2\text{ dB/km}$**（對應滑桿設定值 $0.1$ 或 $0.2$）。
  • 情境 C (極端暴雨 / 強颱侵襲): 模擬海峽遭遇颱風暴雨，建議調整為 **$0.3 \sim 1.0\text{ dB/km}$**。在 $30\text{ km}$ 鏈路下，將產生 $9\sim30\text{ dB}$ 的額外訊號衰耗，可用於論證極端天候下的斷線風險。

二、 障礙穿透/植披損耗 ($L_{\text{veg}}$) 調整策略 (ITU-R P.833)

代表高地發射站視線受到周圍地物、樹林遮擋的非折射性損耗。實際論文應用情境建議：

  • 情境 A (無遮蔽沿海高塔): 天線架設於純岩石山頂或海巡高塔上，設為 **$0.0\text{ dB}$** 以顯現純粹的空間與海面雙路徑干涉。
  • 情境 B (穿越海岸防風林/稀疏枝葉): 模擬高地天線主波束邊緣掃過山坡林木線或海岸防風林，建議設置 **$3 \sim 8\text{ dB}$**，展示邊緣遮蔽效應。
  • 情境 C (深處亞熱帶闊葉林): 模擬發射站完全隱蔽於茂密樹冠層中，微波需強行穿透植物富含水分的葉片，建議大幅拉高至 **$15 \sim 35\text{ dB}$**，藉此論證站點選址 (Site Selection) 錯誤對 MAPL 的致命影響。

三、 多重路徑淡出餘裕 ($F_m$) 調校策略 (ITU-R P.530 / Barnet-Vigants)

為抵禦海面氣象異常（如大氣波導、海面逆溫層、潮汐變化）引發的突發性深衰落，系統工程設計上必須預留的「安全分貝值」。論文情境設計：

  • 情境 A (理論物理極限探討): 單純探討 $1/d^4$ 雙路徑疊加與繞射損耗的物理極限，建議設為 **$0.0\text{ dB}$**，此時計算結果為理論最大通訊極限。
  • 情境 B ($99\%$ 一般海事可用度): 為了抵抗春季海峽常發生的輕度大氣折射變異與潮汐反射點漂移，建議保留 **$10 \sim 15\text{ dB}$** 淡出餘裕。
  • 情境 C ($99.99\%$ 國安/救災級高可靠度): 模擬嚴苛海象與極端大氣波導干擾，為確保通訊絕不斷線，必須保留高達 **$25 \sim 35\text{ dB}$** 的動態淡出餘裕。此時系統顯示之通訊極限距離會大幅縮水，為論文提供「可靠度 vs. 覆蓋半徑」的權衡 (Trade-off) 論點。

📘 高階通訊物理模型與論文引用格式指南 (Technical Appendix & Citation Guide)

一、海面傳播信道、船舶遮蔽繞射與菲涅耳區物理機制

本評估系統整合了國際電信聯盟（ITU）最新發布的建議書規範，專為學術論文（Thesis / Dissertations）提供精準的數值對照與物理機制推導基準：

  • 雙路徑與 $1/d^4$ 平面大地損耗模型（Two-Ray Ground Reflection PL Model）： 當電波射頻路徑存在鏡面海面反射時，接收功率由直射徑與地面反射徑相合疊加。當傳播距離超越第一菲涅耳區臨界物理斷點 $d_{bp}$ 後，反射相位抵消趨於穩定，路徑衰損斜率將從自由空間的 $20\text{ dB/dec}$ 劇增至 $40\text{ dB/dec}$。本系統以動態邊界連續性精準求解交越點： $$d_{bp} = \frac{4 h_t h_r}{\lambda} \quad (\text{m}) = \frac{f_{\text{MHz}} \cdot h_t \cdot h_r}{75000} \quad (\text{km})$$
  • ITU-R P.680-2 海浪相干散射與萊斯衰落：本系統引入 Rayleigh 粗糙度參數 $g$： $$g = \frac{2\pi \sigma_h \sin\theta_i}{\lambda}$$ 海面均方根波高 $\sigma_h = \frac{H_{1/3}}{4}$。當浪高 $H_{1/3}$ 上升，相干反射係數受粗糙度因子 $\rho_s = \exp(-2g^2)$ 指數級衰減，進而動態抑制鏡面破壞性抵消（Fading Null），使萊斯衰落深度變淺、RSSI 相對平穩。
  • ITU-R P.526-16 巨型船舶刀刃繞射與第一菲涅耳清除率： 系統計算 WGS-84 地球曲率與有效海象浪高侵蝕後的鏡面反射點淨空，並結合 P.526 刀刃繞射積分求解巨型船舶桅頂對視線遮擋產生的繞射衰減 $J(v)$。
